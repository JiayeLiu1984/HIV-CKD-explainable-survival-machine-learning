# Exploratory landmark 0 score comparison

Recovered implementations of adapted D:A:D and VHA scores, fold-held-out Cox score-risk mappings and participant bootstrap summaries. Functions are bundled directly rather than extracted at run time from a local notebook. The function names are retained for provenance; they do not mean that the original published scores were fully reproduced.

These scripts require approved private model-ready inputs and the baseline audit input file. No patient input file, predictions or notebook output is distributed. The archived baseline source-date issue is unresolved. See Supplementary Methods and Tables S4a-S4b. This module is distinct from the older baseline RSF workflow.
