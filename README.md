# Explainable Survival Machine Learning Model for CKD Prediction in People with HIV

Reproducible code for the study:

"Development and validation of an explainable survival machine learning model to predict chronic kidney disease among people with HIV: a multicenter prospective cohort study."

The example dataset is a simplified demonstration dataset and includes only the predictors used in the final model. Therefore, the feature selection module in the example workflow is intended to demonstrate the code pipeline rather than to reproduce the full candidate predictor screening process used in the original study.

The workflow includes data splitting, feature selection, model training, model evaluation, and SHAP-based model explainability.

# Workflow overview

The analysis pipeline consists of five modules:

1. Data preprocessing and train-test split  
2. Feature selection  
3. Final model training and hyperparameter tuning  
4. Model evaluation  
5. SHAP explainability  

Each module should be run sequentially because downstream modules depend on outputs generated by earlier steps.

---

# Module descriptions

## Module 1: Data preprocessing and train-test split

Script  

scripts/module_01_data_split.py


This module:

- loads the input dataset
- checks key columns
- separates predictors and survival outcomes
- performs a stratified train-test split
- saves the split datasets

Input


data/example_dataset.csv


Output


data/split_data/X_train.csv
data/split_data/X_test.csv
data/split_data/y_train.csv
data/split_data/y_test.csv


---

## Module 2: Feature selection

Script


scripts/module_02_feature_selection.py


This module:

- trains a full Random Survival Forest model
- computes permutation importance
- removes redundant variables using Spearman correlation filtering
- evaluates sequential feature addition using C-index
- selects the final predictor set

Input


data/split_data/X_train.csv
data/split_data/X_test.csv
data/split_data/y_train.csv
data/split_data/y_test.csv


Output


results/feature_selection/feature_importance.csv
results/feature_selection/final_top_features.csv
results/feature_selection/sequential_feature_selection_results.csv


---

## Module 3: Model training and hyperparameter tuning

# Input data format

The dataset should contain the following key columns:


ID
interval
CKDstatus


Where:

- `interval` = follow-up time  
- `CKDstatus` = event indicator (0 or 1)

Predictor variables should be numeric or convertible to numeric.
